# MindEase: An AI-Powered Mental Health Chatbot 🤖💙

## Overview  
**MindEase** is a mental health chatbot built with **GPT-5** that provides empathetic, friendly, and supportive conversations.  
It helps users cope with stress, anxiety, and everyday emotional challenges by offering mindfulness tips, coping strategies, and an accessible safe space to talk.  

This project was developed as part of a **Hackathon Submission**.  

---

## ✨ Features  
- 🧠 **AI-Powered Conversations** – Built using GPT-5 for natural, human-like interactions.  
- 💬 **Context-Aware Chat** – Remembers conversation flow for better engagement.  
- 🌍 **Voice Chat Support** – User can speak his/her message to the chatbot and it replies back in both voice and text chat.  
- 😌 **Wellness Guidance** – Provides relaxation techniques, coping strategies, and motivational support.  
- 🎨 **Streamlit UI** – Clean and simple user interface for easy interaction.  

---

## 🚀 Tech Stack  
- **Frontend/UI:** Streamlit  
- **Backend:** Python  
- **LLM:** GPT-5 (OpenAI API)  
- **Deployment:** GitHub / Streamlit Cloud
